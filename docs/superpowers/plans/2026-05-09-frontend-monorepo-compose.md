# Frontend Monorepo and Compose Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a customer-facing web application to this repo, keep the Go backend as the system of record, and ship a Compose-first self-hosted deployment that can later grow into a Helm-based distribution without changing the runtime contract.

**Architecture:** The repo becomes a light monorepo with a new `apps/web` Next.js App Router application and the existing Go service left in place. The browser talks to a single origin, with `/` served by the web container and `/api` plus `/auth` reverse-proxied to the Go API; the frontend uses cookie-backed auth owned entirely by the backend. Initial route data should be fetched in Server Components with explicit dynamic caching rules for authenticated pages, while TanStack Query is reserved for client-side refetch, filters, and mutations.

**Tech Stack:** Go 1.25, current stable Next.js App Router, React 19, TypeScript, pnpm workspaces, Tailwind CSS v4, shadcn/ui, TanStack Query, Zod, React Hook Form, Vitest for client-side unit tests, Playwright for E2E, Docker, Docker Compose, Caddy.

**Research-backed decisions:** Use the framework defaults generated by `create-next-app`, keep App Router routes server-first, use shadcn/ui as the initial accessible component baseline on top of Tailwind, prefer `proxy.ts` over `middleware.ts` in newer Next.js, treat authenticated routes as dynamic by default to avoid stale user-specific cache behavior, and use `output: "standalone"` for Dockerized self-hosting.

	}

})

Create `/apps/web/src/lib/api.ts`:

```ts
export async function clientApiFetch<T>(input: RequestInfo | URL, init?: RequestInit): Promise<T> {
  const response = await fetch(input, {
    ...init,
    credentials: "include",
    headers: {
      "Content-Type": "application/json",
      ...(init?.headers ?? {})
    }
  });

  if (!response.ok) {
    throw new Error(`request failed: ${response.status}`);
  }

  if (response.status === 204) {
    return undefined as T;
  }

  return response.json() as Promise<T>;
}
```

Create server-side fetch helpers for App Router routes:

```ts
import "server-only";

export async function serverApiFetch<T>(input: string, init?: RequestInit): Promise<T> {
  const response = await fetch(input, {
    ...init,
    cache: "no-store",
    headers: init?.headers
  });

  if (!response.ok) {
    throw new Error(`request failed: ${response.status}`);
  }

  return response.json() as Promise<T>;
}
```

import type { RepositoryListItem, ScanListItem, ScanManifestItem } from "./types";

export function listRepositoriesServer(baseUrl: string) {
  return serverApiFetch<RepositoryListItem[]>(`${baseUrl}/api/v1/repositories`);

export function listScansServer(baseUrl: string, repositoryId: string, from: string, to: string) {
  const params = new URLSearchParams({
    repository_id: repositoryId,
    from,
    to
  });
  return serverApiFetch<ScanListItem[]>(`${baseUrl}/api/v1/scans?${params.toString()}`);
}

export function getScanServer(baseUrl: string, scanId: string) {
  return serverApiFetch<ScanListItem>(`${baseUrl}/api/v1/scans/${scanId}`);
}

export function listScanManifestsServer(baseUrl: string, scanId: string) {
  return serverApiFetch<{ items: ScanManifestItem[] }>(`${baseUrl}/api/v1/scans/${scanId}/manifests`);
}

export function updateScanMetadataClient(scanId: string, body: { labels: Record<string, string>; annotation: string }) {
  return clientApiFetch<void>(`/api/v1/scans/${scanId}/metadata`, {
    method: "PATCH",
    body: JSON.stringify(body)
  });
}
